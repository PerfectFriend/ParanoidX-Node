📞 Голосовые и видео звонки (WebRTC) — реальная поддержка

Для настоящих звонков между клиентами SimpleX:
1. В обоих клиентах добавьте этот SMP (из верхней секции) для новых контактов (или смените receiving address в карточке контакта).
2. В каждом клиенте: Настройки → Аудио и видео звонки → WebRTC ICE серверы → включите настройку и вставьте строки из карточки 🧊 выше (tcp версия).
3. Создайте контакт/чат используя адрес этого узла → звоните. Сигналинг идёт по SMP, медиа — через наш TURN (скрыт в onion).
Если звонок "проходит" но инициализация не доходит — чат использует не этот SMP для доставки сообщений.
Тестер двух сторон (рекомендую): открой 2 вкладки браузера. Введи одинаковый room. Одна — "Caller", вторая — "Callee". Они автоматически обменяются SDP через этот сервер и используют наш TURN для аудио. Если слышишь друг друга — TURN работает отлично.
