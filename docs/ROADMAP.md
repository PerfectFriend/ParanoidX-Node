### Найденные дефекты (требуют решения)

1. **`apps/isle_app/linux/assets/icon.svg` — не SVG.** Это JPEG 138 КБ,
   переименованный вручную. Flutter на Linux ожидает вектор; сборка
   проходит, но иконка в `.desktop`-launcher отрисуется непредсказуемо.
2. **410 обращений к `Icons.*`** (256 в `isle_app`, 154 в `royal_app`) —
   это ровно та «унылая векторная ерунда из библиотек», которую вы просите
   заменить.
3. **4 Telegram-токена** в `docs/EXPLORATION-REPORT.md` уже вычищены из
   `master`, но старый коммит `4fad97a` доступен по прямой ссылке в
   `PerfectFriend/ParanoidX-Node`.
4. **2 несуществующих relay-адреса** в
   `apps/isle_app/lib/services/relay_manager.dart` — `lgienftf…`,
   `sgztkabf…` не отвечают ни за один скрытый сервис.
5. **`internal/steward/steward.go:165-175`** — команда `auto_recovery`
   переводит экономику в аварийный режим: `silver_backing_ratio 0.70 → 0.50`,
   `treasury_commission_bps 228 → 400`, и **перезаписывает глобальный
   `economy.CurrentParams`**. Это не баг, а задуманный деградационный
   режим, но у него два риска: (а) он мутирует глобальное состояние
   откуда угодно — любой вызов навсегда меняет параметры экономики для
   всего процесса; (б) `Adjust` может вызываться без восстановления.
   Нужен явный `recovery_mode` в состоянии, журналирование и
   подтверждение; в идеале — требовать dry-run перед применением.
6. **`apps/isle_app/lib/services/identity_service.dart:100`** —
   захардкоженный `deviceId = 'simplex-node-device-12345'`.
7. **`install-pack/`** — 32 файла, дубль `docker/`, устаревший
   `node-monitor.py`. Держит репозиторий раздутым и вводит в заблуждение.
8. **3 TODO** в коде (радио-анонсы, Ed25519-подпись запросов, deviceId).
9. **`icon.svg`-подобных подделок** больше нет, но проверки нет — стоит
   добавить в аудит.

## Часть 1. Герб: единая визуальная система

### 1.1. Что имеем

`emblem.png` — круглая печать: красный дракон, глобус с меридианами,
надпись по кругу **SAINT MARY LIBERTY ISLAND**, девиз
**ARDUS ANIMO VINCIT ET PRODIGEST** («Мужество побеждает и умерщвляет
неразумие»), две чёрные пятиконечные звёзды-разделители, белая лента с
чёрной антиквой, двойные красные окружности, чёрный контур.

Это уже полноценная геральдика. Задача — не нарисовать новую, а
**перестать её терять**.

### 1.2. Производные ассеты (сгенерировать один раз, закоммитить)

Все — из одного исходника, с прозрачным фоном где уместно:

| Ассет | Размер | Формат | Куда |
|-------|--------|--------|------|
| `emblem.png` | 640×640 | PNG RGBA | есть, эталон |
| `emblem-mono.png` | 640×640 | PNG, 1 цвет | тай-бар на тёмном, печать в Ч/Б |
| `emblem-gold.png` | 1024×1024 | PNG RGBA | премиум-уровни, печать на бумаге |
| `emblem-seal.svg` | — | SVG | масштабируемо для веба |
| `coat-of-arms.png` | 2048×2048 | PNG RGBA | обои, замена JPEG |
| `wallpaper-desk.png` | 3840×2160 | PNG/JPEG | фон рабочего стола |
| `wallpaper-lock.png` | 1080×1920 | PNG | экран блокировки |
| `pattern-guilloche.png` | 512×512 | PNG, tile | геральдическая сетка-подложка |
| `banner-wide.png` | 2400×600 | PNG | шапка дашборда, соц-шапка |
| `ribbon-motto.png` | 1200×300 | PNG RGBA | девиз отдельно |

**Инструмент:** генератор на Python (Pillow + `cairosvg`) —
`scripts/make-heraldry.py`, чтобы ассеты воспроизводились, а не жили
руками в бин-файлах.

**Правило:** исходник `emblem.png` — единственный источник истины.
Всё остальное генерируется. Правка эмблемы → регенерация → коммит.

### 1.3. Где герб обязателен

**Админка и веб (2 файла, 236 строк — править безопасно)**
- `internal/api/dashboard.html` — герб в шапке, favicon, геральдический
  узор фоном, монограмма в углу
- `internal/api/royal_ui.html` — то же, плюс ширма из двух полей с
  орлом/драконом
- `web/favicon.png` у обоих приложений — заменить пустышки

**Flutter — вместо `Icons.*`**
- `welcome_screen`, `boot_screen`, `onboarding_screen` — полноэкранный
  герб с появлением
- `lock_screen` — герб как обои, ввод поверх
- `dashboard_screen` (оба приложения) — герб в шапке
- `navigation` — вместо `Icons.home`/`Icons.dashboard` — герб-моно
- `CircleAvatar` (6 в `isle_app`) — герб-моно вместо `Icon()`
- splash/launcher на Linux — герб вместо Flutter-логотипа

**Система**
- `.desktop`-файлы обоих приложений → `Icon=paranoidx.png` с гербом
- трей `node-monitor.py` (GTK) — герб в трее, моно-версия
- install-скрипты — баннер с гербом в вывод
- терминальный вывод CLI — ASCII-арт герба в `px-docker.sh --help`

**Печать (Press-пакет, `internal/press`)**
- банкноты TLR: водяной знак герба, микротекст, девиз по краю
- сертификаты `.crt` — герб в расширении x509 (`certificatePolicies`)
- печать `internal/press` — герб в колонтитуле

**Документы**
- `README.md` — герб в шапке, геральдический узор в разделителях
- `AGENTS.md`, `docs/*` — тот же узор в заголовках
- `MANIFEST.md` — печать вместо заголовка

### 1.4. Где НЕ надо

- `simplex_chat_screen` — чат должен остаться чистым, герб в шапке тонкой
  полоской
- транзакционные экраны (кошелёк, биржа) — максимум водяной знак 4%
  прозрачности, чтобы не мешать читать цифры
- `radio_screen` — герб в заглушке «нет потока», не поверх плеера

### 2.2. P1 — продуктовая ценность

**Остров как государство**
- Паспорт жителя: BIP39-кошелёк + onion-адрес + клеймо метки времени
- Территория: интерактивная карта Острова с зонами и правами
- Гражданство: 3 уровня (наблюдатель → подданный → гражданин) с
  разными правами и налогом
- Традиции: календарь праздников острова, привязанный к TLR-эмиссии

**Монетизация без компромисса приватности**
- Подписка `Patron` даёт статус в профиле, а не льготы в протоколе
  (принцип: деньги не дают доступа к данным о других)
- Краудфандинг инфраструктуры: донат на TURN-трафик, на зеркала
- Цифровые сувениры: герб острова как NFT-подобный токен `HERALD`,
  чеканить через существующий TON-пакет

**Радио (11 файлов, `internal/radio` + `acestep`)**
- Расписание эфиров вместо непрерывного потока
- Архив: запись + расшифровка в текст (уже есть announce.go с TODO)
- Голосования за эфир слушателями
- Генерация музыки через ACE-Step с геральдическими обложками

**Press-пакет**
- Настоящие билеты с гербом, водяным знаком и проверкой через API
- Печатный QR для `.onion`-адресов — офлайн-вход без интернета
- Коллекционные выпуски по канонической эмиссии

**Крипта (уже есть `bip39`, `btc`, `eth`, `ton`)**
- Сворачивание ключа по BIP49/BIP84 — детерминированные адреса
- multisig для казны острова (3 из 5)
- отчётность по резервному фонду: сколько серебра в обеспечении TLR,
  публикуемо и проверяемо

### 2.3. P2 — дифференциация

**Приватность как продукт**
- Plausible Deniability для чатов: неотличимые заглушки
- Timing-атаки: постоянный интервал отправки (padding)
- Обфускация метаданных SimpleX-профиля

**Федерация островов**
- Протокол проверки честности: каждая нода публикует Merkle-корень
  своего состояния, соседние острова сверяют
- Кросс-островные переводы TLR с доказательством обеспечения

**ИИ-стейвард (6 файлов)**
- Локальный LLM (Ollama уже подключён, `gemma4`)
- Ответы строго по канону экономики, без «угадывания»
- Аудит решений: каждый ответ со ссылкой на пункт регламента

**Dashboard как Тор-витрина**
- Публичная витрина через `.onion`: статистика, онбординг, статус
- Приглашения по одноразовым ссылкам с TTL

**Расширение экосистемы**
- Плагины радио (FM-модуль)
- Тема-пак: автоматическая генерация цветовой схемы из герба
  (доминирующий красный, золото, чёрный) для всех приложений

## Часть 4. Правила, которые нельзя нарушать

1. **Герб — источник истины.** Правка эмблемы только через генератор.
2. **Никогда не коммитить живые ключи, даже «на пять минут».**
3. **Экономика — только из `reserve.go`.** Никаких параллельных констант.
4. **Force-push — только с `--force-with-lease` на проверенный SHA.**
5. **Приватные репозитории** для всего, что связано с нодой.
6. **Секреты — в `~/A1-backups` с правами 700**, никогда в git.
7. **Перед push — `px-audit-secrets.sh`**, в CI тоже.
8. **Никаких `Icons.*` там, где уместен герб.**
9. **Ноды не трогать без бэкапа** — `px-backup.sh save` первым делом.
10. **Ротация ключей — после того, как адреса перестали быть зашиты в код.**
